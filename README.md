# Eje 4: De una suma finita a la integral definida

Repositorio oficial del **Grupo 4** para la Evaluación Integral Desempeño (EID) del curso **Cálculo Intermedio** de la Universidad Católica de Temuco (UCT).

##  Descripción del Proyecto
Este repositorio contiene el código fuente en **Manim** para la generación del video explicativo y de animación matemática, abordando la transición desde una suma finita de Riemann con rectángulos hasta la integral definida continua, cerrando con un ejemplo numérico resuelto ($f(x) = x^2 + 1$ en el intervalo $[0, 2]$).

---

##  Requisitos Previos e Instalación

Para ejecutar este script y generar el video correctamente, asegúrate de tener instalado en tu equipo:
1. **Python** (Se recomienda versión 3.11 para evitar conflictos con dependencias de compilación).
2. **FFmpeg** (Librería multimedia requerida por Manim).
3. **LaTeX / Pango** (Para el renderizado de fórmulas matemáticas).
